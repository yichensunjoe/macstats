## 这次多了「记忆」

0.3 起，面板不只知道此刻，还知道过去 24 小时。

### 新增

- **24 小时历史**：采样仍是每秒一次，落盘按分钟取平均，按天写成 JSONL，
  放在 `~/Library/Application Support/MacStats/history/`。133 字节/点、约 190 KB/天，默认保留 30 天，可改 7 / 30 / 90 天。
- **面板历史卡**：标准与详细面板多一条「过去 24 小时」，CPU、内存、GPU 三根曲线，各带 24 小时峰值。
  刚开始记录时显示提示，曲线随使用逐渐补全。
- **持续高负载提醒**：CPU ≥ 90%、内存 ≥ 85%、磁盘 ≥ 90%，**连续 3 次采样**才发通知，
  同一指标 10 分钟内不重复。默认关闭，在设置 → 监控里打开。
- **设置 → 监控 →「历史与告警」**：记录开关、保留天数、当前占用大小、一键清空（带确认）。

### 变更

- 标准面板高度 530 → 640，详细面板 430 → 660，给历史卡留出位置；卡片内容不再压到下一张。
- `--snapshot` 支持 `MACSTATS_HISTORY_DIR`，可用指定目录的历史出排版核对图。

### 升级

偏好键没有改动，0.2 的设置与面板位置原样保留；历史从 0.3 首次启动开始积累，不回填。

### 仍然如此

- 需要 macOS 15+、Apple 芯片。
- 本包未公证：首次启动需右键 App →「打开」，或在终端执行
  `xattr -dr com.apple.quarantine /Applications/MacStats.app`。
- 系统小组件约 60 秒一跳，这是 WidgetKit 的调度上限。

验证：103 项单测通过；`codesign --verify --deep --strict` 通过；
`unzip -t` 与 `shasum -a 256 -c` 通过；实机安装后跨分钟自动写盘、进程 0.1% CPU / 98 MB RSS。
