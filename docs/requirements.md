# 需求

## 目标

在 macOS 桌面上放一块常驻的小组件，把活动监视器里 CPU / 内存 / 能耗 / 磁盘 / 网络 的实时状态集中展示，
数值口径与活动监视器一致，随时扫一眼就能判断机器是否吃紧。

## 范围

- 新装默认是 452×80 的极简条状，固定六格（CPU / 内存 / GPU / 能耗 / 磁盘 / 网络），
  用紧凑数字（`45GB`、`79KB/s`）保证任何宽度都排得下；面板窄到一行摆不下会自动折成两行三列，指标一个不藏，
  右键「展开为标准面板」可一键切成下面这块 372 pt 宽的完整面板，再点同一项收回去。
- 一块 372 pt 宽的深色玻璃面板，含 CPU（总量 + 用户/系统 + 每核心条）、内存（已使用/总量 + 压力条 + 构成 + 缓存/压缩）、
  能耗（瓦数 + 电池）、磁盘（读写速率 + 可用空间）、网络（上下行速率 + 主接口）、GPU（利用率 + 显存/核心数 + 趋势线）、
  内存占用最高的 3 个进程。GPU 读数来自 `IOAccelerator` 的 `PerformanceStatistics`，与活动监视器 GPU 页签同源；
  拿不到时（例如部分 Intel 机型）该格显示「不可用」，不影响其它指标。
- 1 秒采样、菜单栏图标显示「CPU · 内存」。右键菜单只留常用操作（显示/隐藏、展开/收成、添加桌面小组件、
  一键清理、清理白名单、打开活动监视器、设置、退出）；置顶 / 点击穿透 / 刷新间隔 / 登录启动 / 白名单
  统一收进「设置…」窗口（⌘,），分「显示 / 后台清理 / 通用」三页。
- 菜单栏与面板右键都有「一键清理后台闲置进程」：只挑当前用户、后台、无终端、非 App、
  且已运行并闲置 10 分钟以上的遗留进程，列清单确认后发 SIGTERM，不强制结束；
  可选白名单按进程名或 `argv[0]`（`ps` 里显示的名字）保护。
- 进程要说人话：设置里可保护的进程、清理确认框里的每个候选，都要有一句「这是什么」和
  「结束它会怎样」；面向完全不懂命令行的人，认不出来就直说是未知后台命令，不编造用途。
  设置里支持搜索、手动输入名字（保护当前没运行的命令）。
- 清理确认 / 结果 / 「没有可清理」都用自定义 SwiftUI 提示窗口，不用系统弹窗。
- 面板位置记忆；退出可恢复。
- 数值与活动监视器逐格对齐（详见 `monitor-alignment.md`）。

## 非目标

- 不做系统「小组件库」（WidgetKit）集成。
- 不做强制结束（SIGKILL）、不做优先级调整、不做开机项管理；清理只针对后台遗留进程，
  每次都要用户确认，且永远不动系统进程、App、终端进程、当前前台 App。
- 不释放文件缓存 / 显存（需要 sudo 或私有接口），不谎称能回收内核缓存。
- 不引入需要 sudo、关闭 SIP 或私有框架的采样手段。

## 约束

- 只用 Mach / IOKit / libproc / sysctl 的公开接口；不采集任何用户数据、不上报网络。
- 目标 macOS 15+，arm64 实测；Swift 6 + SwiftPM，无需 Xcode 工程。
- CPU 开销要低：一次采样只遍历进程列表读 `rusage`，面板刷新不重建窗口；
  清理用的进程表观测 30 秒一次，套接字检查只对已通过其他规则的少量进程做。

## 验收标准

- `cd src && swift test` 全绿（当前 69 项）。
- `.build/debug/macstatsDiag --self-check` 全部 ok。
- 内存五项（已使用 / 缓存 / App / 联动 / 压缩）与活动监视器同步采样偏差 ≤ 0.1 GB。
- CPU 忙百分比与活动监视器 5 秒窗口内差 ≤ 1 个百分点；磁盘累计读写量与活动监视器一致；网络静息态量级一致。
- `bash scripts/bundle.sh` 生成的 `MacStats.app` 双击可启动，桌面上能看到面板且数字在跳动。
- 清理：`.build/debug/macstatsDiag --cleanup-dry-run` 列出的候选必须全部满足
  「当前用户 + 已运行 ≥ 10 分钟 + 已闲置 ≥ 10 分钟 + 无终端 + 无套接字 + 无活着的父/子进程 + 非系统路径 + 非 App」；
  实机用一个自建的孤儿进程验证选中与 SIGTERM 退出。
